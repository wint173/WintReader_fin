# Wint Reader

iOS アプリ「携帯小説⑩」の読書体験を再現する、個人利用の Android 小説リーダーです。

- 対応サイト：小説家になろうグループ・カクヨム・ハーメルン・アルファポリス・ノベルアップ＋・pixiv 小説・青空文庫・Project Gutenberg
- 横書き専用の独自リーダー（ルビ・傍点・ページめくりの演出・スワイプ・スクロール・自動スクロール・本文内検索）
- 本棚（カテゴリ・並び替え・未読話数）、目次・栞、全話の保存、バックアップ

## ダウンロード

最新版の APK：[WintReader.apk](../../releases/latest/download/WintReader.apk)（[リリース一覧](../../releases)）

スマホで上のリンクを開いてダウンロードし、インストールしてください（「提供元不明のアプリ」の許可が必要です）。

- 本文は各サイトから取得し、端末の中だけに保存します。作品の著作権は各作者・各サイトにあります。
- サイトに負担をかけないよう、必要な話だけを間隔を空けて取得します。ログイン・年齢確認・アクセス制限は回避しません。
- 個人で使うためのアプリです。各サイトの利用規約に従ってお使いください。
