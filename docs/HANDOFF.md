## これまでに直した主な不具合（再発したときの手がかり）

- ハーメルン：スマホの UA だと目次が別の形（ul.entry）→両方読む。R-18 は h.syosetu.org。短編は og:title を " - " で分けて題名、
  作者は「作：」＋ユーザーへのリンク。http の挿絵は https に直し、挿絵リンクは本文に埋め込む
- Kotlin の trim() は全角スペース（U+3000）も削るので、題名の分解は文字列の区切りで行う
- Gutenberg：改行で英単語がくっつく → 非 CJK 文字の間の改行は空白に（joinLines）
- 長文で固まる → partialClone（全体を複製しない）
- Compose の composition 中に state を書き換えない（onAutoStopped は state でない入れ物で受ける）
